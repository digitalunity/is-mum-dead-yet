## Deliberately not in scope

- E-commerce, orders or payments.
- A supported plug-and-play product.
- Hardware compatibility guarantees.
- Automatic death/welfare verdicts.
- Publishing telemetry, personal identifiers or details of the real installation.
- Camera imagery inside the home.

## Open technical/product questions

1. Can room classification be made trustworthy enough to give context rather than false confidence?
2. How should the UI make receiver outages, stale timestamps and uncertainty unmistakable?
3. Which Tapo events can be acquired reliably and lawfully without requiring Mum to manage an app?
4. Does the lamp-button event demonstrate a stronger resident-linked signal than passive device activity?
5. How might the system be described so it inspires experimentation without suggesting it is a safety-critical solution?
